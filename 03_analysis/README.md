# analysis
- Mapping: Scripts → Hypotheses
- Brief description of the methods

**H1 (Feature Sensitivity):** Changes in behavior-based input features lead to a significantly larger change in the lead score than changes in static company data.

**H2 (Stability):** Despite identical input, the generated lead scores and their justifications are inconsistent and exhibit a lack of determinism.

**H3 (Explanation Alignment):** In cases where a change in the input influences the score, the causal feature is not consistently cited as the explanatory factor in the self-explanation.

**H4 (Model Differences):** The generated lead scores, their stability, and the associated explanations differ significantly between language models when presented with identical input data.
